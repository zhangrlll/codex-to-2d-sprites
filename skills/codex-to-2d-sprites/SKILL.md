# 3D 模型转 2D 动画素材

用户提供模型和目标，代理自行选择工具、参数、修复方法和采样时机，直到交付可播放的透明素材。默认成品经过 **ImageGen 2D 绘制**；Blender 渲染是姿势底稿。用户明确只要原始渲染时才省略风格化。

## 输入与自主决策

- 读取当前请求、模型及已有生产记录；继续任务时复用已通过检查的阶段，不重新生产整套素材。原始模型保留，修复在副本上进行。
- 不要求用户预先准备配置 JSON、脚本或所有动作。缺少可推定参数时记录假设并继续：默认 4 方向、512 像素画布、每方向约 12 个关键姿势、保留角色身份的简洁 2D 风格。快速动作按连贯性增加采样；已指定的帧数优先，调整前说明原因。
- 动作以用户选择为准；“基础动作一套”可采用 idle、walk、run、roll、jump。前者三种默认循环，翻滚和跳跃默认单次。
- 只在缺少不可替代的输入、需用户完成登录/验证码、必要工具不可用或当前操作确需授权时请求最小帮助。沿用会话已有授权，不设逐阶段确认。用户接手下载时继续检查现有文件，收到新文件后恢复进度。
- 在当前任务目录建立生产记录，保存角色身份、动作来源、方向/帧数/时序、工具可用性和待修问题。配置由代理生成；不把其他角色的外观、磁盘路径或动作范围作为通用默认值。

## 阶段与质量门

| 阶段 | 必须得到的结果 |
| --- | --- |
| 模型与骨骼 | 网格、材质、朝向、尺度、骨架、权重及附件关系可用；测试姿势能正确驱动身体、眼镜、眼睛等。静态权重合格不等于动画绑定合格。 |
| 获取并适配动作 | 优先利用本角色可用动作；缺失时在 Mixamo 筛选、实际预览后选择。核对静止姿态、层级、轴向和比例，不能凭同名骨骼直接套动作。 |
| 动作检查与修复 | 检查完整时间段及接缝：脚滑、关节扭曲、穿模、手臂塌陷、大头穿地、跳跃准备与落地。修复后复查；保存可切换、可播放的绑定源文件。 |
| 多方向抽帧 | 固定正交相机、灯光、世界比例和公共锚点；画布容纳全部动作极值。真实渲染每个方向，保留 RGBA 底稿、来源帧与持续时间。 |
| 关键帧精修 | 先选各方向及动作阶段的代表姿势，用 ImageGen 精修并检查，建立人物风格母版与关键姿势参考。关键帧不合格时先修正，再扩展到附近帧。 |
| 相邻帧精修 | 分段处理关键帧附近的其余输出帧；以每帧对应的 3D 底稿锁定姿势，以母版和附近已通过的关键帧锁定外观。完整覆盖用户要求的最终帧，不能把未处理的 3D 帧混入 2D 成品。 |
| 复检与交付 | 每个动作、每个方向、每一帧均检查，再看连续播放与循环接缝；脚本检查透明度、完整性、切帧和拼接，输出素材包。 |

骨骼适配、Mixamo 下载、Blender action slot、根运动与地面修复：进入相应阶段时读 [references/blender-mixamo.md](references/blender-mixamo.md)。

风格化提示词、绿幕、工作板拆分、对齐、时序及交付检查：进入相应阶段时读 [references/imagegen-delivery.md](references/imagegen-delivery.md)。

## 不变量

- 4 方向顺序为 **S、E、N、W**；8 方向为 **S、SE、E、NE、N、NW、W、SW**。S 是正面，E 朝屏幕右，N 是背面，W 朝屏幕左；先用预览验证旋转符号和模型正面，不能直接套角度或用镜像伪造方向。
- 原地走跑去除整体水平前进，保留自然重心摆动；按用途分离翻滚位移并记录来源。跳跃的竖直运动保留。地面修复只针对异常接触，不能把腾空帧吸到地面。
- 禁止把所有姿势缩到相同人物外框。相机尺度固定；修正 ImageGen 尺寸漂移时，按**对应的源姿势**等比校准，保留下蹲、腾空、倒置的尺寸与位置变化。
- 视觉棋盘格不是透明。核实 alpha；需要备选时优先纯绿背景，检查角色是否含绿色，再按当前工具规则和已有授权抠图。脚本处理不替代 ImageGen 绘制。
- 不让 ImageGen 一次绘制所有动作的最终总图集。风格化的小工作板经过拆分、检查后，再确定性拼接。坏帧需要修复或重绘，不能删除后冒充完整交付。

## 完成与返工

发现错误，定位到模型/动作、渲染或绘制阶段，只重做受影响部分；每次重试改变一个明确原因。同一问题经两次有针对性的修复仍无改善时改用另一可用方法；无法继续则保留通过项，报告具体缺口，不无限盲重试或假称完成。

成品必须覆盖用户指定的全部动作、方向和帧数，具备真实透明 PNG、公共画布/锚点、正确顺序和时序、无明显错肢/裁切/穿地，以及实际播放检查。交付独立帧、动作图集、需要时的总图集、时序清单、GIF/可逐帧预览、带动作的源文件和简短使用说明。保存实际提示词与检查记录，区分画布分辨率和生成插画原始分辨率；明确说明尚存的外观差异。
