How this character was made

从原图到游戏，
每一步都有检查。

这是本项目角色的制作链路。GPT 原图与 Tripo AI 建模是前置准备；这个 Skill 从提供的 3D 模型开始，组织后续生产和复检。

阅读完整工作流 ↗
  1. GPT 原图 → Tripo AI 3D 模型

    先确定角色设计，再将原图交给 Tripo AI 生成模型，准备模型与贴图。

  2. 检查骨骼 → Mixamo 适配动作

    检查蒙皮和附件，按需修复骨骼，为角色选择合适的常用动作，检查变形、脚滑与穿模。

  3. Blender 固定相机 → 多方向帧动画

    固定正交相机、尺度和公共锚点，渲染 4 或 8 个真实方向，保留姿势与帧时长。

  4. GPT Image 精修关键帧 → 附近帧

    先建立角色风格与关键姿势参考，再依照各帧的 3D 底稿精修附近帧，保持身份与动作一致。

  5. 逐帧校验 → 修复 → 连续播放复检

    检查比例、轮廓、呼吸、循环和动作衔接；发现问题后修改受影响部分，再回到播放验证。

  6. 最终素材 → Godot 可操作角色

    导出透明帧和图集，配置八方向 SpriteFrames 与控制器，在实际场景中验证移动、翻滚与跳跃。
